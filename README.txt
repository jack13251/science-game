Welcome to Science Game (still totally just a temporary name only). In this game you must conduct 
experiments using various ingredients and apparatus. As you go you discover more and more things to
use in your experiments.

Right now you need to interact with the sink by walking up to it and pressing F. This discovers impure
water take the water over to the distillation stand and press F again. Then set up your experiment 
and press 'Run Experiment'. UPDATE (week 3): thanks to the newest update the player can now interact
with the computer ('F') after completing the first quest to upgrade to a bigger lab with more
possibilities. Also it is now possible to save and load the game from the new menus. The current
prototype ends after you open the box in the second level.

Controls:
-Movement with the arrow keys
-Interact with 'F'
-Close menu - 'esc'




This game was made in godot using gdScript and is only an early prototype.
