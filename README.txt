Welcome to Science Game (temporary name only). In this game you must conduct experiments using various
ingredients and apparatus. As you go you discover more and more things to use in your experiments.

Right now you need to interact with the sink by walking up to it and pressing F. This discovers impure water
take the water over to the distillation stand and press F again. Then set up your experiment and press 'Run
Experiment'. That's it unfortunately for the prototype but hopefully you get a sense of the concept behind
my game.

Controls:
-Movement with the arrow keys
-Interact with 'F'
-Close menu - 'esc'


This game was made in godot using gdScript and is only an early prototype.
